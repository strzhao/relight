# 叙事原则（B 站 vlog 调研沉淀）

来源：用 opencli 上 B 站搜「vlog 叙事」，分析你的不秃头《百搭VLOG叙事套路》(22万)、影视飓风《Vlog拍摄技巧》(172万)、六斤《万能分镜公式》等。完整调研在 relight task 目录的 `vlog-narrative-research.md`。

## 四原则

### 1. 故事核心 > 技巧
技巧服务于故事。没故事的转场是噪音。95陈先生标题直说「故事才是核心」。**这是判断一切视频效果的标尺。**

### 2. 减法 + 核心创意串全片
别堆技巧。用一个**核心创意**（物品/主题/视角）从头套到尾，所有画面围绕它。
- 物品作主角或暗线：手、蛋糕、一双鞋、一支笔、老相册
- 核心创意 = 你拥有一个可以从头套到尾的切入点

### 3. 章节暗线 + 情绪递进（最有价值）
用一条**递进的线索**把故事分章节。经典案例「和爸爸喝四瓶酒」：
- 第一瓶：拘谨，聊近况 + 童年趣事
- 第二瓶：话变多
- 第三瓶：情绪爆发，父子矛盾（志愿/工作）
- 第四瓶：归于平静，矛盾藏心里，披上外套什么都不想说

**一瓶酒 = 一个章节 = 一次情绪递进。** 暗线串起骨架，故事不再平铺。

### 4. A-roll 叙事 + B-roll 空镜（影视飓风）
- A-roll = 故事核心（对着镜头讲）
- B-roll = 空镜头/分镜穿插避免单调
- **照片视频无讲话 A-roll，用「字幕 + 配乐」承担 A-roll 的叙事功能，照片作 B-roll。**
- 差音频让人立刻关视频 → 配乐/音质极重要

## relight 落地

### 章节暗线（必做）
按内容/时间/情绪分 ~5 章。重庆案例的情绪弧线：
| 章 | 情绪 | 暗线 |
|----|------|------|
| 烟火 | 热闹 | 旅行的温度，从一顿火锅开始 |
| 夜 | 魔幻璀璨 | 山城的魔幻，在灯火里苏醒 |
| 城 | 冷峻 | 几何与混凝土的冷峻秩序 |
| 人 | 温暖 | 空间里的故事与温度 |
| 归 | 宁静 | 三天走过，归于夜的宁静 |

**情绪弧线 = 热闹→魔幻→冷峻→温暖→宁静**（呼应"四瓶酒"的递进）。

### 章节 mood（效果服从气质）
每章附 mood（静/暖/动/烈 4 档），驱动该章镜头的动画+切换效果池——避免「婚礼照配 Flip 翻转」这类全随机违和组合（效果服从叙事气质，是「故事核心 > 技巧」在镜头层面的落地）。映射规则：

| mood | 适用章节 | anim 子池 | trans 子池 |
|------|----------|-----------|------------|
| 静 | 收尾/独处/宁静/回忆/屏息 | 缓推、缓拉、对焦、呼吸 | 淡入、模糊、圆形展开 |
| 暖 | 温暖/相恋/日常/家庭 | 缓推、呼吸、缓旋、对焦 | 淡入、放大切、模糊、圆形展开 |
| 动 | 热闹/旅行/探索/城市 | 横移、纵移、对角、缓推、缓旋 | 左推、下推、放大切、擦除 |
| 烈 | 高潮/爆发/冲突/仪式 | 强推、横移、缓旋、倾斜、对角 | 3D推、缩小切、擦除、放大切 |

- 弧线通常 **静→暖→动→烈→静**（首尾静，中段递进），呼应「四瓶酒」。翁雪珂 5 章：少女暖 / 相恋暖 / 新婚烈 / 孕育静 / 为母暖。
- **flip 翻转对人脸违和**（人脸瞬时消失），不进默认池，仅旅行风景主题酌情启用。
- 章内用确定性伪随机从子池选 anim×trans（相邻去重），效果丰富但不撞违和组合。LLM 提案章节时按内容定 mood，无需逐镜指定。
- 效果池定义在 `video-dryrun/src/scenes/effects.ts`（ANIMS/TRANS/MOOD_POOLS/pickEffectsForChapter），CQ-Immersive 渲染时按章节 mood 自动选池。

### 弧线字幕（必做）
字幕从"描述画面"→"推进情绪"：
- ✗ 红油翻滚，火锅里的山城烟火
- ✓ 山城的第一口，是滚烫的烟火
- ✗ 霓虹点亮天际，孤舟缓行江面
- ✓ 三天走过，山城归于夜的宁静

word（顶部小字）是情绪锚点，不是地名：「烟火」「对望」「追光」「凝望」。

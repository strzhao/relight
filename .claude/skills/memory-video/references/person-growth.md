# 人物成长线（任意命名人物）

把一个命名人物的照片，按**成长/人生弧线**生成短片。已验证 2 人物 × 2 种叙事骨架（合一 / 翁雪珂）。

## 选片（cos 过滤是地基）

1. **cos≥0.5 过滤误识别**：face embedding vs person centroid 余弦相似度。低于 0.5 大概率误识别（用户指认的错误全在 cos<0.4）。embedding base64 解码见 [[relight-db]] 的「人脸 cos 过滤」。
2. **去连拍**：每 burst 留代表（rep=1 优先，否则最高美学分）。
3. **按维度选片**：
   - 成长线（孩子）：按**年**分组，每年美学 + 场景多样选 3-4 张
   - 人生弧线（成人）：按**人生阶段**手挑（少女/相恋/新婚/孕育/为母），不机械按年——13 年跨度按年会出 45 张太多，要精选到 ~16 张

## 叙事骨架（LLM 提案，不硬编码）

引擎**不预设骨架**，由 LLM 读选片的 narrative 提案章节。两种已验证范式：

| 类型 | 骨架 | 实例 |
|------|------|------|
| 孩子 | **年龄里程碑**：稚嫩→好奇→欢腾→远行 | 合一（2022-2026，首尾「睁眼的小→远方的远」）|
| 成人（女） | **人生阶段**：少女→相恋→新婚→孕育→为母 | 翁雪珂（2013-2026，首尾「独自远行→牵手看世界」）|
| 成人（男） | **人生阶段**：初见→立身→远行→成家→为父 | 赵桂雄（2013-2026，首尾「少年独行→抱你重走世界」）|

关键：**弧线字幕推进情绪不描述画面**，word 是成长/人生锚点不是地名。

## 婴儿期 gap（孩子主题的核心难点）

孩子主题有**跨年龄 cos 衰减**：centroid 被近期照片主导（赵合一 2024 占 577/1310 张），婴儿脸（0-3 岁）与当前质心天然不似，cos<0.4 全误识别。
- 实测：赵合一 2019-2021（0-2 岁）cos≥0.5 池 = **0 张（真空）**，2022 也仅 1 张
- **补救（推荐）**：对那几年的低 cos 婴儿照，用 qwen vision 视觉二次确认（"是不是同一个孩子"，对照一张 cos≥0.8 的确信照）。孩子出生日期可从照片最早年份推断，家拍婴儿照大概率是本人。
- **替代**：跳过婴儿期从 3 岁起（合一 dry-run 做法）。成长线缺襁褓但叙事链路完整。

**成人主题无此问题**（翁雪珂 13 年 cos 全 ≥0.5，p50≈0.6）。

## 跨视频去重（亲子照陷阱）

一张亲子照里**母亲和孩子都被识别**，会同时进两人的候选池。
- 实例：`57f52276`（红杉林）、`7d0abe0d`（春节心形）同时在赵合一 + 翁雪珂池
- **dry-run**：手动避开（翁雪珂版用湖畔抱婴/清水墙替代）
- **正式版**：建 `video_usages(photo_id, video_id, theme, created_at)` 表，召回时 JOIN 排除近 N 周用过的照片。同一照片跨主题可复用，但短期不重推。

## persons 表（任意命名人物）

```sql
SELECT id, name, member_count FROM persons
WHERE name IS NOT NULL AND name != '' ORDER BY member_count DESC;
```
当前命名人物：赵合一(1310) / 翁雪珂(867) / 王语晨(142) / 赵桂雄(142) / 徐群仙(137) / 赵锡根(92) / 赵狄苏(27，名字有 `^P` 脏字符待清洗)。

跨度查询（判断适合哪种骨架）：
```sql
SELECT p.name, MIN(ph.taken_at), MAX(ph.taken_at), COUNT(DISTINCT ph.id)
FROM persons p JOIN faces f ON f.person_id=p.id JOIN photos ph ON ph.id=f.photo_id
WHERE p.name=? GROUP BY p.id;
```

## 工具脚本（video-dryrun）

| 脚本 | 作用 |
|------|------|
| `select-person-growth.cjs [person_id] [name]` | cos≥0.5 + 去连拍 + 按年美学/场景多样选片，输出候选清单（含 id）+ ORDER。默认 PER_YEAR=4 |
| `analyze-faces.cjs` | 单人物 cos 分布（p10/p50/max + 各阈值剩余数 + 最低/最高 cos 照片），判断 cos 质量是否健康 |
| `convert-{name}.cjs` | 原图转 1080p JPEG（sips -Z 1920 + hard fail，见 [[remotion-setup]]） |

**人生阶段精选**（成人）：脚本按年输出候选后，从里手挑人生事件代表（旅行/婚礼/孕期/亲子）16 张 5 章。后续可让 LLM 做这个精选。

## 未命名聚类（name=null）也能出片

`daily-video` 发现逻辑会给 **name=null 的人物聚类**出片（非只命名人物）。处理要点：
- **身份确认**：用 qwen vision 看几张代表照（开场/转折/近期）判断主角是谁、是否同一人；再查该聚类 centroid 与所有命名人物 centroid 的 cos——全 <0.7 即独立人物（非已知人物重复聚类），如 36f9ab3d vs 赵桂雄仅 0.337。
- **标题策略**：name=null 时用描述性标题（如「父与子 · 八年时光（2018–2026）」），不用 `<名字> · 成长线`。视频内 CQ_TITLE 用短词（如「父与子」）。
- **叙事骨架**：与命名成人相同（LLM 按 narrative 提案人生阶段），不机械按年。36f9ab3d 八年弧线核心转折是 2020 初为人父。
